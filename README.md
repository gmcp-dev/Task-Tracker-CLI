# Task Tracker CLI

This small projects follows a list of projects provided by [Roadmap.sh](https://roadmap.sh/projects). This in specific, is at [Task Tracker](https://roadmap.sh/projects/task-tracker).

It was made with Javascript with [Node.js](https://nodejs.org/es) environment. It follows a simple logic to perform certain operations about task to add, update, delete and change its status.
